# Результаты выпуска

Файлы — сохранённые результаты реального локального прогона. Полный повтор:
`bash verify.sh`; новые результаты появятся в `artifacts/release`.

`report.html` открывается в браузере после скачивания. `report.json` содержит
метрики и fingerprint проверенного кода. `verified_source_commit` указывает
коммит с тем же fingerprint; `versions.revision` сохраняет состояние Git
именно в момент запуска, включая признак ещё не закоммиченных изменений.

80/80 автоматических проверок = 90/90 баллов автоматической части. I01–I05
подготовлены для человека, но баллы за них не присвоены. Статус официальной
заявки эти файлы не подтверждают.

`trajectories.jsonl` — открытые train/dev-траектории. Приватные результаты
локального benchmark находятся только в офлайн-комплекте на стороне оценщика;
они никогда не передаются обычному агенту.
