# Состояние первого среза

Реализованы финансовые правила первого профиля, два ручных эпизода, причинный
генератор дублей и недораспределения, независимый валидатор, reset/step, инструменты,
пагинация, ограниченный калькулятор, matcher и reward. Есть четыре базовые
политики; обычные политики работают в изолированном контейнере.

## Граница текущей готовности

Это первый этап, а не завершённая заявка на 100 баллов. Число пройденных тестов
текущего ядра не равно баллам полной матрицы в `planning/acceptance-matrix.json`.

Следующие обязательные работы:

1. FX с объявленной датой курса, валютными разрядностями и округлением.
2. Ошибки периода и взаимодействие FX/период.
3. Возвраты, отсутствующие ссылки, дополнительные чистые случаи и профили сложности.
4. Полные JSON-схемы всех файлов, 10 train и 10 dev эпизодов.
5. Полная матрица 80 проверок, новые конфигурации и пять инженерных критериев.
6. Измерение ресурсов всего решения, комплект сдачи и финальное демо.

Генератор пока создаёт один платёж на счёт. Текущий профиль не поддерживает
иностранные валюты, возвраты, ошибки периода и неоднозначные распределения.
Они не выдаются за корректно проверенные возможности.

## Известные условия эксплуатации

Python 3.11 и Docker на Linux. Быстрый запуск unittest без флага контейнерных
тестов пропускает проверки изоляции. Полный запуск — `./verify.sh`.
Для `--offline` образ агента должен быть заранее собран из текущего кода.
Финальные артефакты содержат приватные отчёты доверенного запуска; передавать
их обратно политике во время закрытой проверки нельзя.

Ручные примеры намеренно малы. Стандартный генератор выдаёт более 200 проводок.
При переименовании и перестановке сохраняются выводы и награда oracle;
качество любой произвольной политики этим не гарантируется.

## Уточнения организаторам

Нужны точные определения официальных проверок, entrypoint политик, канонические
affected IDs, семантика сумм по типам, формат invoice_refs и представление
закрытой reward. До получения этих сведений действует явно опубликованный
локальный контракт, для официального интерфейса предусмотрен адаптер.
