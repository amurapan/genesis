# Комплект сдачи

Содержимое `dist/evidable-submission.zip` готово для распаковки в папку Google Drive:
исходники, учебные данные, лицензия, схемы, два Docker-образа, локальный отчёт,
траектории, презентация, демо и файл со ссылкой на GitHub. Все суммы и компании
вымышлены. Данные из личных финансовых аккаунтов не используются.

После распаковки команда `bash run-offline.sh` сначала проверяет контрольные
суммы, загружает образы из локального архива и запускает полную проверку.
Нужны Linux, Python 3.11, Docker и cgroup v2; сеть не используется.

Исходники: https://github.com/amurapan/genesis

## Демонстрация

[Открыть MP4](https://sled-genesis.vercel.app/assets/demo.mp4) ·
[Текст озвучки с таймкодами](../demo/narration.md) ·
[Субтитры SRT](../demo/captions.srt).

Видео — **2 минуты 17 секунд, 1920 × 1080, 25 кадров/с, без звука**.
Команда добавляет свой голос поверх готовой записи; текст и SRT приложены
для монтажа. Это запись экрана работающего приложения и двух настоящих
запусков Python CLI:

| Время | Что показано |
| --- | --- |
| 00:00–00:12 | Лендинг и объёмный архив документов |
| 00:12–00:35 | Запуск агента в Docker: FX + ошибка периода, 2 TP, 0 FP, 6 действий |
| 00:35–01:05 | Документы и воспроизведение сохранённой траектории в лаборатории |
| 01:05–01:32 | Проводка, курс и граница периода — проверяем доказательства |
| 01:32–01:50 | Запуск на чистой компании: частичная оплата, пустой список нарушений |
| 01:50–02:08 | Результаты локальных проверок и устройство изоляции |
| 02:08–02:17 | Команды для самостоятельного запуска |

Лаборатория воспроизводит публичные траектории, а CLI выполняется во время
записи. Выводы новых прогонов совпали с опубликованными примерами. Терминальный
сценарий показывает читаемое представление фактического результата после
завершения; исходный JSON и траектории лежат в `demo/fx-period/` и `demo/clean/`.
Оценка 90/90 относится только к автоматической части нашей локальной матрицы,
не к проверке жюри. Десять инженерных баллов требуют оценки человеком.

Повтор одного эпизода после подготовки Docker-образов по README:

```bash
PYTHONPATH=src python3 -m sled demo --fixture fixtures/manual_fx_period.json
```

### Повторная запись видео (необязательно)

Для записи нужны Linux/X11, Xvfb, xterm, Python 3.11, Node.js 22+, Chrome,
uv и FFmpeg с libx264. Скрипт использует Playwright Core 1.65.0 и MSS 10.1.0.
Эти инструменты не нужны для проверки финансовой среды. Версия FFmpeg,
контрольные суммы видео и результаты прогонов записаны в `demo/media-tools.json`.

Запустите в двух отдельных терминалах:

```bash
Xvfb :98 -screen 0 1920x1080x24 -nolisten tcp
```

```bash
python3 -m http.server 4174 --directory web
```

В третьем терминале, из корня репозитория:

```bash
npm install --no-save --package-lock=false playwright-core@1.65.0
DISPLAY=:98 CHROME_BINARY="$(command -v google-chrome-stable)" node scripts/record_demo.mjs
python3 scripts/make_demo.py
```

`CHROME_BINARY` должен указывать на установленный Chrome; для другой команды
Chrome укажите её путь. Для терминала в записи установлен шрифт JetBrains Mono.
Запись управляется скриптом, клики и команды выполняются в настоящих приложениях.
Сырые фрагменты попадают в игнорируемый Git каталог `artifacts/live-demo/`.
Сборщик объединяет их без ускорения, обновляет MP4, текст озвучки и SRT в `demo/`,
`web/assets/` и `artifacts/demo-release/`. Паузы между сценами вырезаны;
голос и музыка не генерируются. Пересборка требует исходных записанных фрагментов.

## Презентация

[PDF](../demo/presentation.pdf) и [редактируемая PPTX](../demo/presentation.pptx)
содержат 12 слайдов на русском и отдельные заметки докладчика в PPTX.
Публичные версии: [PDF](https://sled-genesis.vercel.app/assets/presentation.pdf),
[PPTX](https://sled-genesis.vercel.app/assets/presentation.pptx).

Сохранены градиенты и композиционные элементы предоставленного командой
шаблона `Purple and Yellow Gradient Marketing Plan Presentation.pdf`.
Весь текст и примерные показатели шаблона заменены материалами evidable.
Скриншот сделан с работающего веб-демо; метрики взяты из
`verification/report.json`. QR-код ведёт на публичное демо.

PDF содержит встроенные русские шрифты. Для редактирования PPTX без подмены
шрифта установите Montserrat Regular и Bold из
[`demo/presentation-assets/fonts`](../demo/presentation-assets/fonts).
Лицензия шрифтов — SIL OFL 1.1, приложена в `OFL.txt`. В PPTX текст, таблицы
и схемы редактируются, градиентные фоны сохранены изображениями.

Пересборка из включённых фонов, шрифтов и скриншота:

```bash
uv run --no-project --with pymupdf==1.26.6 --with python-pptx==1.0.2 \
  --with qrcode==8.2 --with pillow==12.0.0 python scripts/make_presentation.py
```

Команда обновляет PDF/PPTX в `demo/`, `web/assets/` и существующем каталоге
`artifacts/demo-release/`. Оригинальный шаблон для повторной сборки не нужен.
Файл `demo/presentation-info.json` фиксирует источник оформления, версии
инструментов, fingerprint проверенного ядра и SHA-256 итоговых файлов.
Эти инструменты не нужны для запуска финансовой среды.
