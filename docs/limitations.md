# Область применимости и ограничения

Поддерживается явно ограниченный профиль дебиторской задолженности. Счета
номинированы в базовой валюте; поступления могут быть в KZT, USD, EUR, JPY и KWD.
Разрядности 0/2/3 и оба режима округления проверяются. FX-курсы вымышленные.
Нет валютных счетов к получению, переоценки задолженности, НДС, банковских комиссий,
курсовых доходов и полноценной ERP-модели.

Платёж относится к одному счёту либо имеет явный null. Разбитая оплата — несколько
платежей к одному счёту. Возврат касается нераспределённой переплаты: например,
счёт 100, поступление 120, возврат 20. Возврат уже распределённой оплаты и
кредит-ноты не реализованы. Это документированные границы генератора, а не
скрытые задания для агента. Избыточные строки формируются дроблением законных
кредитовых проводок; сложность из одного количества строк не выводится.

Время хранится с явным фиксированным смещением. Есть границы периода и крайние
смещения +14/-12, но нет календаря IANA с переходами DST. Граница периода
полуоткрытая: начало включено, конец исключён.

Простая сверка обычно решает поддерживаемый профиль полностью. Высокий F1
показывает разрешимость задач, но не сложность для произвольной модели, не
обобщение на реальные компании и не улучшение после RL. Oracle проверяет только
верхнюю границу награды. Дополнительные 200 эпизодов и выбранные мутации не
являются исчерпывающим доказательством корректности.

Доверенными считаются Linux kernel, Docker daemon, launcher и evaluator.
Отдельный процесс оценщика сам по себе не изолировал бы произвольный агент;
изоляцию даёт контейнер без mounts/socket/network. Защита от container escape
не заявляется. На хосте нужны Python 3.11, Docker и cgroup v2 для измерений памяти.
Сумма измеренных максимумов памяти включает launcher, evaluator и агент, но не
общий Docker daemon. Во время benchmark broker/evaluator делят одно CPU-ядро,
агент ограничен квотой одного CPU; служебные процессы Docker в эту квоту не входят.

Публичные train/dev содержат доступный исследователю эталон, но их private-каталоги
не доступны агенту. Закрытые seed локального прогона сохраняются у оценщика для
повтора; после публикации архива они перестают быть секретом для людей. Это
локальная приёмка, а не скрытая выборка организаторов. Для нового независимого
прогона удалите только `artifacts/release/private/holdout-config.json` в своей копии.

80 локальных проверок составлены по ТЗ и не являются официальным набором жюри.
Инженерные I01–I05 требуют ручного просмотра. Итоговые 100 баллов нельзя
гарантировать, даже если все собственные проверки зелёные. Полная официальная
спецификация адаптера и трактовка отдельных полей остаются внешней зависимостью.
